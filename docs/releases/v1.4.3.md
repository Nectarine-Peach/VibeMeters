# VibeMeters v1.4.3

로그인 창과 창 상태 복원 동작을 수정한 업데이트입니다.

- **터미널 없는 로그인:** Codex·Claude 공식 CLI를 백그라운드에서 실행하고 브라우저 인증을 진행합니다. 창을 열었다는 안내 대신 실제 로그인 결과를 확인한 뒤 사용량을 갱신하며, 5분 안에 완료되지 않으면 대기를 종료합니다.
- **창 크기·위치 보존:** 이동·크기 변경을 자동 저장하고 닫기·Windows 종료·절전 때 마지막 상태를 저장합니다. 업데이트 후 기본 크기로 되돌아가던 동작을 제거했습니다.
- **자동시작 상태 복원:** Windows 시작 시 저장된 창 크기·위치와 표시 또는 트레이 상태를 복원합니다. 이전 모니터가 없으면 보이는 화면으로 옮깁니다.

## 업데이트

1. 기존 앱의 트레이 메뉴에서 **종료**를 선택하세요.
2. 첨부된 **VibeMeters-win-x64.zip** 전체를 압축 해제하세요. Gemini에 필요한 `runtime` 폴더도 함께 유지해야 합니다.
3. `VibeMeters.exe`를 실행하세요. 기존 개인 설정은 유지됩니다.

**Windows 10/11 x64**용 .NET 포함 포터블 배포본입니다. Codex·Claude 로그인은 공식 CLI 설치가 필요하며, 브라우저에서 사용자가 인증을 완료해야 합니다.

<summary>English release notes</summary>

This update fixes sign-in windows and saved window-state restoration.

- **Sign in without a terminal:** Codex and Claude official CLIs run in the background and open browser authentication. Usage refreshes after the login result is checked, rather than treating a launched process as a completed login. Waiting ends after five minutes.
- **Preserve window size and position:** Moving or resizing saves automatically, with a final save on close, Windows shutdown, or sleep. Updates no longer reset the window to a default size.
- **Restore startup state:** Windows startup restores the saved size, position, and visible-window or tray state. If a previous monitor is missing, the window moves onto an available screen.

Quit the existing app from its tray menu, extract the **entire VibeMeters-win-x64.zip**, and run `VibeMeters.exe`. Keep the included `runtime` folder; existing preferences are preserved. Requires **Windows 10/11 x64**; .NET is included. Codex and Claude sign-in requires their official CLI, and you must complete authentication in the browser.

See the linked verification notes for the scope and results of checks. Use the attached `.sha256` file to check package integrity.
