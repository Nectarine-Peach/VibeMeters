# VibeMeters v1.4.14

가로·세로 작업표시줄에서 위젯 기본 높이를 46 DIP로 통일했습니다. 한도가 한 줄이거나 사용량을 일시적으로 조회할 수 없어도 다른 서비스와 같은 높이로 표시됩니다.

- 여러 위젯의 너비를 실제 화면 픽셀 단위로 나눠, 공간이 충분한데도 마지막 위젯이 빠지는 문제를 수정했습니다. 세로 작업표시줄에서는 공간이 좁을 때 위젯 높이를 함께 줄입니다.
- 작업표시줄 버튼 사이에서 가장 넓은 연속 빈 공간을 찾아 위젯을 배치합니다. Windows가 위젯 창을 숨기거나 닫으면 다음 배치 주기에 복원합니다.

업데이트하려면 트레이 메뉴에서 VibeMeters를 종료하고 ZIP 전체를 새 폴더에 푼 뒤 `VibeMeters.exe`를 실행하세요. [Windows x64 ZIP 다운로드](https://github.com/Nectarine-Peach/VibeMeters/releases/download/v1.4.14/VibeMeters-win-x64.zip)

<summary>English release notes</summary>

Widgets now share a default height of 46 device-independent pixels on horizontal and vertical taskbars. A service with a single quota or an unavailable reading keeps the same height as its neighbors.

- Widget widths are allocated in screen pixels so rounding can no longer hide the last widget when there is room for it. On a crowded vertical taskbar, widgets shrink together.
- VibeMeters finds the largest continuous gap between taskbar controls. If Windows hides or closes a selected widget, VibeMeters restores it on the next placement cycle.

To update, exit VibeMeters from the tray menu, extract the entire ZIP into a new folder, and run `VibeMeters.exe`. [Download the Windows x64 ZIP](https://github.com/Nectarine-Peach/VibeMeters/releases/download/v1.4.14/VibeMeters-win-x64.zip)
