# VibeMeters v1.4.6

최신 README와 네 서비스 화면을 Windows 배포 ZIP에 포함한 업데이트입니다. v1.4.5의 조회·로그인·설정 동작은 유지합니다.

- **최신 계정 안내:** 개인 Gemini(Antigravity)와 회사 Code Assist를 구분하고 Grok Build 구독 범위를 상단 지원 표와 계정 안내에서 확인할 수 있습니다. Codex Business 개인 한도·Claude Enterprise 월 추가 사용 안내도 포함합니다.
- **네 서비스 이미지 9종:** Codex·Claude·Gemini Antigravity·Grok Build의 표준/라이트/미니/최소 폭/설정 화면과 캡처 기록을 포함합니다. 이미지는 실제 WPF 컨트롤을 합성 데이터로 렌더링한 예시이며 실계정 수치나 OS 데스크톱 캡처가 아닙니다.
- **압축 해제 후 문서 보기:** 한/영 README와 docs 폴더를 함께 배포하고 이미지·상대 문서 링크가 ZIP 안의 파일로 연결되는지 확인합니다.

## 업데이트

1. 기존 앱을 트레이 메뉴에서 **종료**하세요.
2. 첨부한 **VibeMeters-win-x64.zip 전체**를 새 폴더에 압축 해제하세요.
3. `VibeMeters.exe`, `runtime`, README 및 `docs`를 함께 유지하세요. 기존 개인 설정은 유지합니다.

Windows 10/11 x64용 .NET·Node 포함 Portable입니다. Antigravity·Grok 연동에는 해당 공식 CLI와 사용자 로그인이 필요합니다. ZIP의 README 파일은 로컬 Markdown 뷰어에서 열 수 있으며 이미지·문서는 상대 경로로 연결됩니다.

이번 배포 검증은 최종 커밋의 Release 컴파일/패키징, 계정 없는 Gemini 내장 runtime 진단, ZIP 원본 파일/이미지 해시·상대 링크 및 원격 asset 무결성 확인에 한정합니다. 사용자 요청으로 회귀·UI 스모크·실제 설치·실계정 조회/로그인은 실행하지 않습니다. 상세 범위는 [검증 기록](https://github.com/Nectarine-Peach/VibeMeters/blob/v1.4.6/VERIFICATION.md), [캡처 안내](https://github.com/Nectarine-Peach/VibeMeters/blob/v1.4.6/docs/screenshots/README.md)를 참고하세요.
