# VibeMeters v1.4.7

앱 UI에 영어를 추가했습니다. Windows UI 언어가 한국어이면 한국어, 그 외에는 영어로 시작하며 설정의 **언어 / Language**에서 **시스템 / 한국어 / English**를 선택해 즉시 전환하고 저장할 수 있습니다.

- 메인 카드·설정·트레이·알림·툴팁·접근성 이름·설치/로그인/오류 안내를 현지화합니다.
- 표시 언어만 바꾸며 제공자 원문 snapshot·제품명·API 및 한도 식별자는 유지합니다. 언어 변경으로 새 조회나 로그인을 실행하지 않습니다.
- 영문 레이블 폭과 설정 배치를 조정하고 최신 영문 화면·언어 설정 안내를 ZIP에 포함합니다.

기존 앱을 트레이에서 종료하고 **VibeMeters-win-x64.zip 전체**를 새 폴더에 압축 해제하세요. EXE·runtime·README·docs를 함께 유지합니다. 기존 설정은 유지되며 언어 값이 없는 이전 설정은 시스템 기본값을 사용합니다.

최소 컴파일과 합성 영문 캡처에서 한→영→한→영 전환, 캐시/설치 상태 원문 복원 및 레이블 폭을 확인했습니다. 전체 회귀/UI 스모크·실제 설치·실계정 조회/로그인은 사용자 요청으로 실행하지 않았습니다. 최종 배포 검사는 Release self-contained 패키징, 계정 없는 Gemini 내장 진단과 ZIP/원격 asset 무결성 확인입니다.

<summary>English release notes</summary>

VibeMeters now supports English and Korean throughout the app. The System default uses Korean for Korean Windows UI languages and English otherwise. Choose System, 한국어 or English in Settings → Language; the selection is saved and applied immediately.

Cards, settings, tray, notifications, tooltips, accessibility names and installation/sign-in/error guidance are localized. Provider snapshots, product names and protocol identifiers remain unchanged, and switching language does not fetch quotas or sign in again. English screenshots and language instructions are included in the ZIP.

Extract the entire Windows x64 ZIP and retain its runtime and documentation folders. Existing settings are preserved. Compilation and synthetic localization captures include repeated Korean/English switching and cached/status restoration. Full regression/UI smoke tests and actual installation/live account checks were skipped at the user's request. Release packaging and the existing account-free Gemini runtime diagnostic are performed.
