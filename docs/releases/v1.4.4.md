# VibeMeters v1.4.4

회사 계정 한도 표시와 로그인 복구를 개선하고, 기능을 유지하면서 Gemini 배포 런타임을 줄였습니다.

- **Codex Business 개인 한도:** 서버가 제공한 개인 한도 비율과 초기화 시각을 표시합니다. 5시간·주간 구독 한도와 구분합니다.
- **Claude 월 추가 사용:** Enterprise를 포함해 활성화된 월 추가 사용 비율을 표시합니다. 비율이 없는 정상 응답에는 임의의 수치를 만들지 않습니다.
- **계정 전환·로그인 안내:** 로그인 성공 뒤 이전 계정 수치와 성공 캐시를 지우고, 서버의 429 대기는 유지합니다. 인증서·프록시·SSO·콜백 포트 오류를 구분하며 공식 로그인 호스트만 브라우저 복구에 사용합니다.
- **필요할 때 공식 CLI 설치:** 로그인에 필요한 Codex CLI·Claude Code가 없으면 설치 또는 취소를 선택합니다. 명시적으로 선택한 뒤에만 공식 사용자 설치를 진행하고, 실패 시 재시도하며 설치 확인 후 로그인으로 이어집니다. 기존 인증으로 조회할 때는 설치를 요구하지 않습니다.
- **슬림 Portable:** `node_modules` 전체 대신 Gemini 공식 코어 0.65.0의 번들과 라이선스를 배포합니다. 기존 Node 24.22.0과 .NET을 동봉하므로 사용자 PC에 .NET·Node·npm을 설치할 필요가 없습니다.

## 업데이트

1. 실행 중인 앱은 트레이 메뉴에서 **종료**하세요.
2. 첨부한 **VibeMeters-win-x64.zip 전체**를 새 폴더에 압축 해제하세요.
3. `runtime` 폴더를 EXE 옆에 유지하고 `VibeMeters.exe`를 실행하세요. 기존 개인 설정·CLI 인증 위치는 유지합니다.

Windows 10/11 x64용입니다. Codex·Claude 로그인은 공식 CLI와 사용자의 브라우저 인증이 필요하며, CLI가 없으면 앱에서 공식 설치를 선택할 수 있습니다. 회사 SSO·관리자 정책 및 공급자의 내부 API 변경 영향을 받습니다.

CLI 설치 기능 추가 전에는 회귀 139개와 실행 창 검사 239개를 통과했습니다. 추가 후에는 사용자 요청으로 회귀·UI 검사를 생략하고 컴파일/패키징과 Gemini 내장 runtime 진단만 수행했습니다. 실제 CLI 설치·계정 재로그인·SSO·Gemini 실계정 조회는 실행하지 않았습니다. 검증 범위와 제한은 [검증 기록](https://github.com/Nectarine-Peach/VibeMeters/blob/v1.4.4/VERIFICATION.md), [CLI 설치](https://github.com/Nectarine-Peach/VibeMeters/blob/v1.4.4/docs/cli-installation.md), [계정 안내](https://github.com/Nectarine-Peach/VibeMeters/blob/v1.4.4/docs/account-usage.md), [패키징 안내](https://github.com/Nectarine-Peach/VibeMeters/blob/v1.4.4/docs/packaging.md)를 참고하세요. `.sha256` 파일로 ZIP 무결성을 확인할 수 있습니다.

<summary>English release notes</summary>

This release adds Codex Business individual limits and enabled Claude monthly additional usage, clears old account values after explicit sign-in while preserving rate-limit cooldowns, and improves sign-in error guidance.

When a sign-in CLI is missing, the app offers explicit official user-scoped installation with progress, cancellation and retry before sign-in. Existing authenticated usage polling does not require the CLI. No CLI installation or account sign-in was exercised in this release run; regression/UI checks were skipped at the user's request after this feature was added.

The Gemini adapter now ships as a bundle instead of the full node_modules tree. The official core remains 0.65.0 and the bundled Node runtime remains 24.22.0. .NET and Node are included; no separate runtime installation is required. Extract the entire ZIP and keep its runtime folder beside the EXE. Existing settings and CLI authentication locations are unchanged.

Codex and Claude sign-in still require their official CLI and user browser approval. See the linked verification record for tested behavior and limitations.
