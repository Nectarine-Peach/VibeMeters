# VibeMeters v1.4.15

작업표시줄 위젯을 알림 영역 쪽에 배치하고, 설정에서 Codex CLI·Claude Code·Antigravity CLI를 설치하거나 업데이트할 수 있게 했습니다. 설정은 **일반**과 **계정 · CLI** 두 탭으로 정리했습니다.

- **작업표시줄 위치:** 가로 작업표시줄에서는 오른쪽 알림 영역 바로 왼쪽의 빈 공간을 사용합니다. 중앙 시작·앱 버튼 왼쪽의 더 넓은 공간으로 이동하지 않습니다. 세로 작업표시줄은 알림 영역 쪽 끝을 사용하며, 좁은 폭에서는 로고 위·한도 행 아래 형태로 표시합니다. 한도 이름·그래프·수치·리셋 시간을 같은 행에 맞췄습니다.
- **위젯 표시 복구:** 위젯이 작업표시줄 뒤로 가거나 최상위 표시 속성을 잃으면 포커스를 가져오지 않고 복구합니다. 같은 작업표시줄의 상태를 잠시 읽지 못하면 마지막 정상 위치를 최대 6초 유지합니다. 읽을 수 있는 공간이 없으면 일부 위젯을 숨기며 자동 숨김·전체 화면 제외 처리는 유지합니다.
- **CLI 관리:** **설정 → 계정 · CLI → CLI 설치 및 업데이트**에서 설치 상태와 버전을 확인하고 **설치** 또는 **업데이트**를 한 번 눌러 시작합니다. 진행 중 같은 버튼으로 취소할 수 있습니다. 기존 native·npm·WinGet 설치 방식을 사용하고, 실패하면 해당 행에 안내합니다. 로그인은 별도로 진행합니다.
- **설정 화면:** 기본 크기에서는 두 탭 모두 스크롤 없이 표시합니다. 작은 창이나 긴 오류 안내에서만 얇은 스크롤을 사용합니다. 탭을 바꿔도 CLI 작업과 상태를 유지하며 설정 창을 닫으면 진행 중 작업을 취소합니다.
- **Claude 연결과 이전 수치:** 느린 npm shim의 버전 확인을 최대 30초 기다리고, 실행 파일이 바뀌기 전까지 성공한 지원 버전을 재사용합니다. 조회 제한·재시도 중에도 공급자가 유효한 이전 수치를 유지하면 사용량 창과 위젯에 함께 표시하고 툴팁에서 이전 확인값임을 알립니다.

검증에는 .NET 회귀 325개와 최종 설정 레이아웃 43개 성공 근거를 사용했습니다. 설치·업데이트는 합성 실행기로 검증했으며 실제 CLI 설치나 로그인을 실행하지 않았습니다. Windows 11 가로 작업표시줄 실기와 사용자의 실제 포커스 전환 현상은 재현하지 못했습니다. [검증 범위](../../VERIFICATION.md) · [설정 화면](../screenshots/README.md) · [CLI 관리](../cli-installation.md)

업데이트하려면 트레이 메뉴에서 VibeMeters를 종료하고 ZIP 전체를 새 폴더에 푼 뒤 `VibeMeters.exe`를 실행하세요. `runtime` 폴더를 EXE 옆에 두면 됩니다. 기존 설정과 CLI 인증을 다시 사용할 수 있습니다.

<summary>English release notes</summary>

Taskbar widgets now stay near the notification area. Settings can install or update Codex CLI, Claude Code and Antigravity CLI, with separate **General** and **Accounts · CLI** tabs.

- **Taskbar placement:** Horizontal taskbars use the gap immediately before the notification area, keeping widgets to the right of centered Start/apps controls. Vertical taskbars use the notification end and stack the logo above quota rows when the bar is narrow. Quota labels, graphs, values and reset times share aligned rows.
- **Widget recovery:** Placement restores widgets that lose their topmost state or fall behind the taskbar, without activating them. A temporary taskbar scan failure can reuse the last successful geometry for at most six seconds. Limited space hides some widgets while preserving readable widths. Existing auto-hide and full-screen handling remains in place.
- **CLI management:** Under **Settings → Accounts · CLI → CLI installation and updates**, check installed versions and click **Install** or **Update** once to start. The same button becomes **Cancel** while running. Maintenance uses the existing native, npm or WinGet installation and reports failures in the service row. Sign-in remains separate.
- **Settings layout:** Both tabs fit without scrolling at the default size. Smaller windows and long errors use a slim scrollbar. Switching tabs preserves CLI work and its status; closing Settings cancels active work.
- **Claude connection and previous readings:** Slow npm shims have up to 30 seconds to report their version, and supported successful versions are reused until the executable changes. During a rate-limit wait or retry, widgets retain the same previous measurements as the dashboard when the provider still considers them valid. Tooltips identify them as previous values.

Validation includes successful evidence from 325 .NET regression checks and 43 final settings layout checks. CLI installation and updates used fake command execution; no real installer or sign-in ran. A physical Windows 11 horizontal taskbar and the user's foreground-switch symptom were not reproduced.

To update, exit VibeMeters from the tray menu and extract the whole ZIP into a new folder. Keep `runtime` beside `VibeMeters.exe`. Existing preferences and CLI authentication are reused.
