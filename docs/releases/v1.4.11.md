# VibeMeters v1.4.11

Claude의 인증 만료 복구와 네 서비스의 사용량 조회를 개선했습니다.

- **Claude**는 만료 2분 이내에 사용량을 조회할 때 공식 Claude Code로 인증 갱신을 시도합니다. 자동 갱신에는 **Claude Code 2.1.317 이상**이 필요합니다. 조회 제한 대기 시각은 앱을 다시 시작해도 유지됩니다. 일시 오류 중에는 같은 인증으로 30분 이내에 확인했고 아직 초기화되지 않은 한도만 **이전 값**으로 표시합니다. [Claude 인증과 업데이트 안내](https://github.com/Nectarine-Peach/VibeMeters/blob/v1.4.11/docs/account-usage.md#claude-인증-자동-갱신과-재로그인-표시)
- **Codex**는 인증 파일이 없거나 읽히지 않을 때, 또는 사용량 서버가 401을 반환할 때 설치된 공식 Codex CLI에서 계정과 한도를 다시 확인합니다.
- **Gemini Code Assist**는 조회가 제한되면 기본 10분을 기다리며, 서버가 더 늦은 재시도 시각을 지정하면 그때까지 기다립니다.
- **Grok**은 조회 중 공식 Build CLI가 새 인증을 저장하면 한 번 더 조회합니다. 인증이 다시 바뀌면 결과를 버리고, 조회 제한을 받으면 대기 시간을 적용합니다.

기존 앱을 트레이 메뉴에서 종료한 뒤 ZIP 전체를 새 폴더에 풀고 `VibeMeters.exe`를 실행하세요. `runtime` 폴더는 EXE 옆에 두세요. 기존 설정과 CLI 로그인을 재사용합니다. 실행 경로를 옮겼고 자동시작을 사용한다면 설정에서 **Windows 시작 시 실행**을 껐다 켜세요. [Windows x64 ZIP 다운로드](https://github.com/Nectarine-Peach/VibeMeters/releases/download/v1.4.11/VibeMeters-win-x64.zip)

릴리스 준비 중 .NET 회귀 285개, WPF 스모크 304개, Node 테스트 7개, Gemini 번들 오프라인 검사 2개를 통과했습니다. 실제 Claude 사용량 조회에서 인증 만료 전 HTTP 200을 확인했습니다. 실계정의 만료 후 자동 갱신과 나머지 서비스의 실계정 조회는 이 검증에서 확인하지 못했습니다. 새 화면 이미지는 합성 데이터로 렌더링했습니다. <summary>English release notes</summary>

- **Claude** tries to renew authentication when a usage check falls within two minutes of expiry. Automatic renewal requires **Claude Code 2.1.317 or later**. Rate-limit waits survive app restarts. During a temporary failure, the app shows a **Previous** reading only if it is less than 30 minutes old, came from the same credential, and the quota has yet to reset. [Claude renewal and CLI updates](https://github.com/Nectarine-Peach/VibeMeters/blob/v1.4.11/docs/account-usage.md#claude-인증-자동-갱신과-재로그인-표시)
- **Codex** checks the account and quota through the installed official Codex CLI when the credential file is missing or unreadable, or when the usage endpoint returns 401.
- **Gemini Code Assist** waits ten minutes after a rate limit and honors a later retry time supplied by the server.
- **Grok** checks quota once more if the official Build CLI changes its credentials during a lookup. The app discards the result if the credentials change again and honors any rate-limit wait.

Exit VibeMeters from the tray menu, extract the full ZIP into a new folder, and run `VibeMeters.exe` with the `runtime` folder beside it. The app reuses your settings and CLI sign-ins. If you moved the executable and use automatic startup, toggle **Start with Windows** off and back on. [Download the Windows x64 ZIP](https://github.com/Nectarine-Peach/VibeMeters/releases/download/v1.4.11/VibeMeters-win-x64.zip)

Release preparation passed 285 .NET regression checks, 304 WPF smoke checks, seven Node tests and two offline Gemini bundle checks. A live Claude usage lookup returned HTTP 200 before token expiry. This validation did not confirm live renewal after expiry or live account lookups for the other services. The new screenshots use synthetic data.
