# VibeMeters v1.4.9

새로고침 요청과 사용량 상태 표시를 개선했습니다.

- 수동 버튼·F5·트레이와 설정 주기의 자동 조회가 표시 중인 서비스의 정상 성공 캐시를 우회합니다. 429/Retry-After, 인증·실패 보호 대기는 유지합니다. 더 짧은 주기는 실제 조회 요청을 늘릴 수 있습니다.
- 조회 중 들어온 수동 요청은 한 번으로 합칩니다. 해당 요청 이후 완료된 결과가 있으면 중복 네트워크 요청 없이 사용합니다.
- 카드와 툴팁에 마지막 수치 관측, 결과 확인, 보호 대기 종료와 다음 가능한 자동 조회 시각을 구분합니다. 계정 변경으로 수치를 지우면 이전 관측 시각도 지웁니다.

`다음 자동`은 설정 주기와 보호 대기로 계산한 다음 가능한 타이머 시각입니다. 실행 예약이나 정시 조회를 보장하지 않으며 진행 중 조회·Windows 잠금/절전·타이머 지연으로 더 늦어질 수 있습니다. 캐시 재사용 시 기존 관측/확인 시각을 유지합니다.

ZIP 전체를 새 폴더에 압축 해제하고 EXE·runtime·문서를 함께 유지하세요. 기존 설정은 보존됩니다. 이번 검증은 최종 커밋의 Release self-contained 빌드·패키징, 무계정 Gemini 내장 진단과 ZIP/원격 asset 무결성 확인으로 제한했습니다. 회귀·전체 UI 스모크·실계정·CLI 설치·현재 앱 교체는 생략했습니다. 포함된 기존 스크린샷은 이전 버전의 합성 캡처입니다. [검증 범위](https://github.com/Nectarine-Peach/VibeMeters/blob/v1.4.9/VERIFICATION.md).

<summary>English release notes</summary>

Manual refresh (button, F5 or tray) and scheduled polling now bypass successful-result caches for visible services. Rate-limit/Retry-After, authentication and failure protection waits remain in force. A shorter polling interval can increase actual requests. Manual requests made during a lookup are combined into one pending request, and results completed after that request can satisfy it without duplicate network calls.

Cards and tooltips distinguish the last quota observation, result/error check, protection expiry and next possible automatic timer tick. Account changes clear the old observation time together with quota values. Cached results retain their original observation/check times. The next automatic time is calculated from the interval and protection deadline, not a reserved or guaranteed execution time; in-flight work, Windows lock/sleep and timer delays can defer it.

Extract the entire ZIP and retain runtime and documentation. Existing settings are preserved. Publication checks cover the final-commit Release self-contained build/package, account-free Gemini diagnostic and archive/remote asset integrity. Regression/full UI smoke, live account checks, CLI installation and local app replacement were skipped. Included screenshots are synthetic captures from earlier versions.
