# VibeMeters v1.4.2

Codex·Claude·Gemini의 사용량을 작은 Windows 트레이 창에서 확인하세요.

- 미니 창과 큰 창에 같은 카드 구성과 세로 한도 행을 적용했습니다.
- 표시할 서비스와 서비스별 남은 양·사용한 양을 선택할 수 있습니다.
- 항상 위, 트레이 상주, 작업표시줄 표시와 Windows 자동시작을 지원합니다.
- 다크·라이트·시스템 테마와 자동·수동 새로고침을 제공합니다.
- Gemini 할당량을 앱 안에서 표시하는 공식 CLI 코어 런타임을 포함합니다.

## 설치

1. 아래 첨부 파일의 **VibeMeters-win-x64.zip**을 다운로드하세요.
2. ZIP 전체를 고정된 폴더에 압축 해제하세요. `runtime` 폴더도 함께 유지해야 합니다.
3. `VibeMeters.exe`를 실행하고 설정에서 서비스 계정을 연결하세요.

**Windows 10/11 x64**용이며 .NET이 포함된 포터블 배포본입니다. 기존 앱이 실행 중이면 트레이 메뉴의 **종료**를 선택한 뒤 업데이트하세요. 개인 설정은 기존 위치에 유지됩니다.

<summary>English release notes</summary>

VibeMeters is a compact native Windows tray monitor for Codex, Claude, and Gemini quotas.

- Consistent service cards and vertical quota rows at standard and mini sizes.
- Select visible services and remaining or used percentages independently.
- Always on top, tray residence, optional taskbar icon and Windows startup.
- Dark, light, and system themes; automatic or manual refresh.
- Bundled official Gemini CLI core runtime for in-app quota display.

Download **VibeMeters-win-x64.zip**, extract the entire package including `runtime`, and run `VibeMeters.exe`. Connect your accounts in Settings. Requires **Windows 10/11 x64**; .NET is included. Quit an existing instance from its tray menu before replacing files. Existing preferences are preserved.

Verification: **97 regression checks and 197 window/layout checks passed**. Window checks use shown-window WPF render captures at 125% scaling; live account login and provider availability were outside this run. Use the attached `.sha256` file to check package integrity.
