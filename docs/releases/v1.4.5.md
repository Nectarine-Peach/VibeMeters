# VibeMeters v1.4.5

Gemini 개인 계정의 Antigravity 사용량 경로와 공식 Grok Build 구독 조회를 추가했습니다. Codex Business 개인 한도·Claude Enterprise 월 추가 사용 및 기존 CLI 설치 안내는 유지합니다.

- **Gemini · Antigravity:** Code Assist가 개인 계정에 `UNSUPPORTED_CLIENT`를 반환하면 설치된 공식 Antigravity CLI 1.4.7 이상의 `/usage`로 전환합니다. Gemini 5시간·주간·제공되는 Argon 한도를 표시하며 타 제품 한도나 Gemini 웹·앱 한도와 섞지 않습니다. 회사 계정의 유효한 Code Assist 경로는 유지합니다.
- **Grok Build:** 설치된 공식 CLI의 구독 비율과 초기화 정보를 표시합니다. 응답에 따라 **Build 전용**과 **공유 구독** 범위를 구분하며, 제공되지 않는 Grok Bot 한도·API 비용·추가 사용 금액은 만들지 않습니다.
- **계정 전환과 조회 보호:** Grok은 인증 파일 내용 대신 수정 시각을 감시하고, 조회 중 계정이 바뀌면 결과를 버립니다. Gemini와 Grok 모두 계정 변경으로 429 대기를 우회하거나 이전 계정 비율을 이어 표시하지 않습니다.
- **네 서비스 설정·트레이:** Codex·Claude·Gemini·Grok 표시와 남은 양/사용한 양을 선택합니다. Gemini와 Grok은 기본적으로 꺼져 있습니다. Grok CLI·Antigravity CLI나 브라우저 확장을 자동 설치하지 않습니다.

일반 조회는 모델 생성이나 브라우저 로그인을 실행하지 않습니다. Grok은 ACP 초기화와 billing 조회만, Antigravity는 버전을 확인한 뒤 공식 사용량 명령만 사용합니다. 로그인 버튼은 사용자가 선택했을 때만 공식 로그인 경로를 엽니다.

## 업데이트

1. 기존 앱을 트레이 메뉴에서 **종료**하세요.
2. 첨부한 **VibeMeters-win-x64.zip 전체**를 새 폴더에 압축 해제하세요.
3. `runtime` 폴더를 EXE 옆에 유지하고 `VibeMeters.exe`를 실행하세요. 기존 설정은 유지합니다.

Windows 10/11 x64용 .NET·Node 포함 Portable입니다. Antigravity와 Grok 연동에는 해당 공식 CLI와 사용자 로그인이 필요합니다. 지원 범위는 계정·CLI/서버 응답과 회사 정책에 따라 달라집니다.

이번 릴리스 작업에서는 사용자 요청으로 회귀·UI 스모크·실제 설치·실계정 조회/로그인을 생략합니다. 배포 검증은 최종 커밋의 Release 컴파일/패키징, 계정 없는 Gemini 내장 runtime 진단과 ZIP/원격 asset 해시 확인에 한정합니다. 이전 개발 시점 테스트와 계정 관측은 [검증 기록](https://github.com/Nectarine-Peach/VibeMeters/blob/v1.4.5/VERIFICATION.md)에서 구분합니다.

<summary>English release notes</summary>

This release routes unsupported personal Gemini accounts to the installed Antigravity CLI's official usage command while preserving valid business Code Assist access. It also adds official Grok Build subscription polling, with explicit Build-only versus shared quota labels, account-change protection and four-service settings/tray support.

Polling sends no model-generation or browser-login request. Antigravity and Grok require their installed official CLI and user authentication; neither CLI nor a browser extension is automatically installed. Gemini and Grok are off by default.

Extract the entire Windows x64 ZIP and keep its runtime folder beside the EXE. .NET and the existing Node 24.22.0 runtime are included. At the user's request, this release run skips regression/UI tests, actual CLI installation and live account login/quota checks. Release compilation/packaging and the existing account-free Gemini runtime diagnostic are performed; earlier development evidence is separately dated in the verification record.
